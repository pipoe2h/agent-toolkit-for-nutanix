# Installation notes

For the skills published from the `skills/` directory, use the open installer:

```bash
npx skills add <owner>/agent-toolkit-for-nutanix/skills
```

This repo's setup prompt refers to files inside the repository and therefore expects the user to have cloned the repository or to use an agent that can fetch those raw files. This prototype does not install an MCP server, manage Prism Central credentials, or change client config automatically.
